# Art

Drop finished drawings here as transparent PNGs. The file name must match a key
in `src/art.ts`, and the image should be the size listed there. Anything that
isn't here yet is drawn as a placeholder, so art can arrive one file at a time.

| File | Size (px) | What it is |
| --- | --- | --- |
| `lauren.png` | 32 x 48 | Lauren standing, facing right |
| `ground.png` | 32 x 32 | Ground tile (top surface) |
| `dirt.png` | 32 x 32 | Ground tile (below the surface) |
| `platform.png` | 32 x 16 | Floating platform tile |
| `small_talk.png` | 32 x 32 | Enemy: Small Talk, a walking speech bubble |
| `coffee_mug.png` | 14 x 14 | Thrown coffee mug (flaming) |
| `sharp_wits.png` | 28 x 8 | Sharp wits spell beam, pointing right |
| `flame.png` | 8 x 8 | Flame particle |
| `background.png` | 640 x 360 | Sky / far background, scrolls slowly |

Animations (running, jumping) come next; each will be a row of frames in one PNG.
